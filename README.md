# KaziLink

KaziLink connects Kenyan businesses with digital freelancers. The frontend is a
Vite/React application in the project root.

## Run the frontend

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

The app currently uses its existing local mock data and browser persistence.
Supabase backend setup and environment configuration will be documented here
once the Supabase implementation is in place.

## Frontend scripts

- `npm run dev` — start the Vite development server.
- `npm run build` — create a production build.
- `npm run preview` — preview the production build.
